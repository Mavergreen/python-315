This installs CPython 3.15, built to run on Mac OS X 10.9 (Mavericks) and later, Intel and Apple Silicon alike, into /usr/local/mavergreen/python315/.

Open a new Terminal window: python3-315 is on your PATH, and so are python3, python3.15 and python while this is the selected Python line. Your shell searches /usr/bin first, so on 10.9 a bare python still finds the system's Python 2.7 and python3 finds this one, and on modern macOS a bare python3 finds Apple's /usr/bin/python3 and python finds this one. The system's own Python is left alone.

This release has no ssl module and no pip; a later release adds them. IDLE and tkinter are not included.

A background updater (Sparkle) checks daily for new releases. Built from python.org's source. This is an unofficial community build, not affiliated with or supported by the Python Software Foundation.
